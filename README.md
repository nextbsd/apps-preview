# Preview

Images and PDFs on NextBSD, as NeXTSTEP's Preview and macOS's: open a file
from File Viewer, page through it, zoom, rotate, print or export it.

- **Images:** PNG, JPEG, TIFF, GIF and the other formats GNUstep reads, with
  a sidebar of the folder's other images and a slideshow.
- **PDF:** pages, thumbnails in a sidebar, search, and copying text.

Installed by the NextBSD desktop as `/System/Applications/Preview.app`, built
by [nextbsd-desktop](https://github.com/nextbsd/nextbsd-desktop). Work is
tracked in [nextbsd/nextbsd](https://github.com/nextbsd/nextbsd).
